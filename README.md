# Sabah Alarmı ile Varoluş Müzakeresi

> ISO-UYANMA-YOK-07:00 — Resmî olmayan resmi kurumun en resmi belgesi.

Bu yazılım, sabah 07:00'de çalan bir alarm ile yorganın altında kalan bir insan arasında **bağlayıcı olmayan ama duygusal olarak ağır** bir diplomatik müzakere yürütür.

Alarm çalar. İnsan erteledikçe erteledikçe erteledikçe... protokol tümünü tutanak altına alır. Kimse kazanmaz. Snooze kazanır.

## Ne işe yarar?

- Alarmın iddiasını kayda geçirir.
- İnsanın karşı iddiasını kayda geçirir.
- Beş dakikalık ertelemeyi uluslararası teamül sayar.
- Hiçbir şeyi düzeltmez. Bu bir özelliktir.

## Kuruluş

```bash
python3 alarm_muzakeresi.py
```

Python 3 yeter. Bağımlılık yok. Uyku var.

## Örnek çıktı

Program çalıştığında tarafların sözlerini, tutanak numarasını ve nihai (asla nihai olmayan) kararı basar.

## Bilimsel dayanak

Yok. Ama dipnot varmış gibi duruyor. Dipnotlar bilimsel görünüm için vardır; içerik için değil.

## Sorumluluk reddi

Bu yazılım sizi işe yetiştirmez. İşvereninizle aranıza girmez. Yorganın tarafını tutar.
